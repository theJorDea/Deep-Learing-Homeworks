# ДЗ-1. Свёртки, обучение сетей и устойчивость

Решение: [hw1.ipynb](hw1.ipynb). Ответы на вопросы стоят после соответствующих заданий, результаты запусков и графики сохранены внутри ноутбука.

Выполнены разделы 1–4, 5.1, вариант 5.2 (`targeted`) и раздел 6. Бонусы: 7.1, 7.2, 7.4, 7.5 — суммарно 4 балла. Ветки 5.3 и 7.3 не выбраны.

Для запуска нужно установить зависимости из `requirements.txt` и выполнить ноутбук сверху вниз. Итоговый режим — `FAST_MODE=False`. Использован GPU NVIDIA RTX 3060, 12 GB. Точные версии находятся в `artifacts/environment.json`; `requirements_actual.txt` содержит версии использованного окружения с CUDA 12.8.

В `artifacts/` лежат метрики и три checkpoint обязательной части. Датасеты загружаются автоматически в `data/` и в репозиторий не входят.

По разделам:

- **1:** свёртка как умножение матриц, её производные и область влияния входных пикселей.
- **2:** нормализация по каналам и объединение Conv+BatchNorm при оценке.
- **3:** масштаб значений в глубокой сети, AdamW и уменьшение learning rate.
- **4:** ResNet на CIFAR-10 и сравнение plain-сетей одинакового бюджета.
- **5:** атаки меняют пиксели по градиенту; targeted добивается конкретного класса.
- **6:** обучение на атакованных изображениях и проверка более сильными атаками.
- **7:** кривизна loss, FFT, атака по нескольким пикселям и проверка срыва устойчивости при FGSM-обучении.

Материалы: [семинары курса](https://github.com/Dv1t/ITMO-2026-DEEP-LEARNING-SEMINARS) и ссылки в условии ноутбука.
